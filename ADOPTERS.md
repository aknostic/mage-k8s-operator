> Not affiliated with, endorsed by, or sponsored by Adobe Inc.

This is a list of organisations running mage-operator. It shows
maintainers and other users who is running the operator, in which
environments, and on which providers. It also counts towards the
[beta criteria](ROADMAP.md#beta), which include three adopters
running in staging.

mage-operator is alpha software. Listing here is not an endorsement,
and a staging entry is as useful to us as a production one.

## Adopters

| Organisation | Environment | Stores | Provider | Since |
|---|---|---|---|---|
| *No entries yet. Yours could be the first.* | | | | |

Columns:

- **Organisation:** your organisation's name, or `anonymous`. Link
  to your site if you like.
- **Environment:** `staging` or `production`. If you run both, add
  one row for each.
- **Stores:** the number of `MageStore` resources you run in that
  environment.
- **Provider:** where the cluster runs, for example `Scaleway
  Kapsule`, `EKS` or `on-prem`.
- **Since:** the month you started, as `YYYY-MM`.

## Add yourself

Open a pull request that adds one row to the table above. Keep rows
in alphabetical order by organisation, with `anonymous` rows last.
You do not need to ask first, and a docs-only PR needs no
`CHANGELOG.md` entry.

If you would rather not edit a file, open an
[adoption report](https://github.com/aknostic/mage-k8s-operator/issues/new?template=adoption_report.yml)
and we will add the row for you.

Only list what you are happy to make public. You can ask to be
removed or changed at any time with a pull request or an issue.
